# Samuel Praise Etah — portfolio

A single-page personal site: plain HTML, CSS and JavaScript, no build step and no dependencies.
Open `index.html` in a browser to preview it.

## Publish

1. Push this folder to a GitHub repository.
2. On vercel.com: **Add New → Project → Import** that repository. Framework preset: **Other**. Leave the build command empty and the output directory as the root. Deploy.

Every push to `main` redeploys the site automatically.
